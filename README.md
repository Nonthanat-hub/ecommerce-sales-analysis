# E-commerce Sales & Customer Analytics

**Data Analytics Portfolio Project | Python • SQL • Excel • Power BI**

## About This Project

An end-to-end data analytics portfolio project focused on understanding e-commerce sales performance, product trends, customer purchasing behavior, and transaction patterns.

The project demonstrates practical data analytics skills through data preparation, exploratory data analysis, SQL business analysis, reporting, and dashboard development.

The ultimate goal is to transform raw transaction data into meaningful business insights that support data-driven decision-making.

## Dataset

**Online Retail II Dataset**

- Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii)
- Creator: Daqing Chen
- Period: December 2009 – December 2011
- Records: Approximately 1 million transactions
- License: CC BY 4.0

The dataset contains historical online retail transactions from a UK-based online retailer.

## Project Objectives

1. Evaluate sales performance and revenue trends.
2. Identify best-selling and highest-revenue products.
3. Analyze customer purchasing behavior.
4. Measure repeat purchase activity.
5. Examine cancellations and return patterns.
6. Develop reports and dashboards.
7. Translate analytical findings into business recommendations.
