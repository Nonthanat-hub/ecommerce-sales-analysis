
# E-commerce Sales & Customer Analytics

**Data Analytics Portfolio Project | Python • SQL • Excel**

## About This Project

This project focuses on analyzing historical e-commerce transactions to understand sales performance, product trends, customer purchasing behavior, and return patterns.

The goal is to demonstrate practical data analytics skills through data cleaning, exploratory data analysis, SQL queries, and business reporting.

## Dataset

**Online Retail II Dataset**

- Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii)
- Creator: Daqing Chen
- Period: December 2009 – December 2011
- Records: Approximately 1 million transactions
- License: CC BY 4.0

The dataset contains historical online retail transactions from a UK-based online retailer.

## Project Objectives

1. Analyze sales performance and revenue trends.
2. Identify best-selling products.
3. Analyze customer purchasing behavior.
4. Measure repeat purchase activity.
5. Examine cancellations and return patterns.
6. Create reports and visualizations to communicate business insights.

## Key Business Questions

- How do sales change over time?
- Which products generate the most revenue?
- Who are the highest-value customers?
- How frequently do customers make repeat purchases?
- What patterns can be found in cancellations and returns?

## Project Workflow

4. SQL Business Analysis
