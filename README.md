E-commerce Sales & Customer Analytics

A data analytics portfolio project focused on exploring e-commerce transactions, understanding customer behavior, and generating actionable business insights.

Project Overview

This project analyzes historical online retail transactions to identify sales trends, top-performing products, customer purchasing behavior, and return patterns.

The goal is to demonstrate practical skills in data cleaning, exploratory data analysis, SQL querying, and business reporting.

Dataset

Online Retail II Dataset

* Source: UCI Machine Learning Repository
* Period: December 2009 – December 2011
* Records: Approximately 1 million transactions
* License: CC BY 4.0

Dataset attribution: Daqing Chen, UCI Machine Learning Repository.

Tools & Technologies

* Python

* SQL
* SQLite
* Microsoft Excel
* Matplotlib / Seaborn
* Git & GitHub

Project Objectives

1. Analyze overall sales performance and revenue trends.
2. Identify top-selling products.
3. Analyze customer purchasing behavior.
4. Measure repeat customer activity.
5. Examine cancellations and return patterns.
6. Present business insights through reports and visualizations.
