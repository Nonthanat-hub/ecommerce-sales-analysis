# Project Plan: E-commerce Sales & Customer Analytics

## 1. Project Goal

Analyze real-world e-commerce transaction data to identify sales trends, product performance, customer behavior, and business opportunities.

## 2. Dataset

- Name: Online Retail II
- Source: UCI Machine Learning Repository
- Period: December 2009 – December 2011
- Data Type: Historical retail transactions
- License: CC BY 4.0

## 3. Analysis Scope

### Sales Analysis
- Monthly revenue trends
- Sales performance
- Revenue by country

### Product Analysis
- Best-selling products
- Highest revenue-generating products
- Product performance

### Customer Analysis
- Top customers by revenue
- Repeat purchase behavior
- Customer segmentation

### Transaction Analysis
- Cancellations
- Returns
- Order quantity and value
